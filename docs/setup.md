# 本文分析ノート　準備の手順（v6）

> **もう使っている場合** は、下の「v5 から v6 に上げる」（前の版を使っている場合は、その前の「〜に上げる」も）から読んでください。初めての場合は、手順1から順番に進めます。

上から順番に1つずつ進めてください。かかる時間は30分くらいです。
パソコンの Chrome で作業します。教室で使っている Google アカウントでログインしておいてください。

> 画面の文字は、Google の更新で少し変わることがあります。見つからないときは、似た名前のボタンを探してください。

---

## 手順1　スプレッドシートを作る

1. Chrome で **https://drive.google.com** を開く。
2. 左上の **「＋ 新規」** を押す。
3. **「Google スプレッドシート」** を押す（右に出る小さい矢印ではなく、文字のところ）。
   - 新しいタブで、空のスプレッドシートが開きます。
4. 左上の **「無題のスプレッドシート」** という文字を押す。
5. `本文分析ノート データ` と打って、Enter を押す。

## 手順2　Apps Script（GAS）を開く

1. いま開いているスプレッドシートの、上のメニューの **「拡張機能」** を押す。
2. **「Apps Script」** を押す。
   - 新しいタブで、プログラムを書く画面が開きます。
3. 左上の **「無題のプロジェクト」** を押す。
4. `本文分析ノート` と打って、**「名前を変更」** を押す。

## 手順3　プログラムを貼る

1. Apps Script の画面の左にある **「コード.gs」** を押す（英語の画面なら「Code.gs」）。
   - 右に `function myFunction() {` と書かれた画面が出ます。
2. 右の画面のどこかを1回押してから、キーボードで **Ctrl + A**（全部選ぶ）→ **Delete**（消す）を押す。
3. パソコンのフォルダ `honbun-check` の中の `gas` フォルダを開く。
4. `Code.gs` を **右クリック** →「プログラムから開く」→ **「メモ帳」** を押す。
5. メモ帳で **Ctrl + A**（全部選ぶ）→ **Ctrl + C**（コピー）を押す。メモ帳は閉じてかまいません（保存はしない）。
6. Apps Script の画面にもどって、右の白い所を1回押してから **Ctrl + V**（貼りつけ）を押す。
7. 上にある **💾（フロッピーの形）「プロジェクトを保存」** を押す（または Ctrl + S）。

## 手順4　シートを自動で作る（setup を1回だけ実行）

1. 上の **「▷ 実行」** ボタンの右にある、関数の名前が出ている欄（最初は `doGet` などと出ています）を押す。
2. 一覧から **`setup`** を押す。
3. **「▷ 実行」** を押す。
4. 初めてのときは **「承認が必要です」** という画面が出ます。次のように進みます。
   1. **「権限を確認」** を押す。
   2. 自分の Google アカウントを押す。
   3. 「Google はこのアプリを確認していません」と出たら、左下の小さい **「詳細」**（または「詳細を表示」）を押す。
   4. 一番下の **「本文分析ノート（安全ではないページ）に移動」** を押す。
      - 自分で作ったプログラムなので大丈夫です。
   5. **「許可」**（または「続行」）を押す。チェックボックスが出たら、全部にチェックを入れてから押す。
5. 画面の下に「実行ログ」が出て、**「準備ができました。」** と出たら成功です。
6. スプレッドシートのタブにもどる。下に **Lessons・Students・Teachers・Assignments・Drafts・Submissions・Settings** の7枚のシートができています。

## 手順5　教室コードとパスワードを決める

1. スプレッドシートの下の **「Settings」** シートを押す。
2. `classCode` の右（B2 のマス）を押して、**教室コード** を打つ。生徒に教える言葉です。
   - 例：`shinyashiki2026` のように、英語の小文字と数字にすると打ちやすいです。
3. `teacherPass` の右（B3 のマス）を押して、**講師パスワード** を打つ。講師にだけ教えます。
   - 生徒に知られると答えが見えてしまうので、教室コードとはちがう、推測されにくい言葉にしてください。
4. `adminPass` の右（B4 のマス）を押して、**管理パスワード** を打つ。教室長だけが使います。講師パスワードとはちがう言葉にしてください。
5. 打ったら Enter。保存は自動です。
6. **大事：** だれかが講師や教室長としてログインすると、打ったパスワードは自動で「元にもどせない暗号の形」に変わります。
   - `teacherPass` のマスは空になり、下に `teacherPassHash` という行ができて、`sha256$…` という長い文字が入ります。`adminPass` も同じです。
   - この長い文字は、さわらないでください。
   - **パスワードを変えたいとき** は、空になった `teacherPass`（または `adminPass`）のマスに新しいパスワードを打つだけです。次のログインのときに、また暗号の形に変わります。前のパスワードでログインしていた人は、ログインし直しになります。
   - パスワードを忘れたときも、同じように新しいパスワードを打てば大丈夫です。

## 手順6　生徒と講師を入れる（テスト用はあとで直してもOK）

最初は、テスト用の「テスト 生徒A〜C」（生徒番号 `T01`〜`T03`、PIN `1111` `2222` `3333`）と「テスト先生」が入っています。まずはこのまま手順7〜8で動くことを確かめ、そのあとで本物の名前を足すのがおすすめです。

- **Students シート**：1行に1人。
  - `studentId`：重ならない番号（例：`S01`）
  - `name`：名前
  - `grade`：学年（`中1` `中2` `中3`。**レッスンの grade と同じ書き方** にする）
  - `pin`：**4けたの数字**（例：`0427`）。生徒がログインするときに使います。生徒ごとにちがう数字にして、本人にだけ教えてください。
    - `0` で始まる数字も、そのまま打てば大丈夫です（シートが文字として残します）。
    - PIN が空の生徒はログインできません。
    - PIN を変えると、その生徒はログインし直しになります。
    - PIN を5回続けてまちがえると、その生徒は10分間ログインできなくなります。
  - `active`：`TRUE`。やめた生徒は `FALSE` にすると、一覧から消えます（データは残ります）
- **Teachers シート**：1行に1人。`teacherId`（例：`K01`）、`name`（例：`田中先生`）、`active`（`TRUE`）。
- テスト用の行は、本番が始まったら `active` を `FALSE` にしてください。

## 手順7　ウェブアプリとして公開する

1. Apps Script のタブにもどる。
2. 右上の青い **「デプロイ」** を押す → **「新しいデプロイ」** を押す。
3. 左の **「種類の選択」の横の ⚙（歯車）** を押す → **「ウェブアプリ」** を押す。
4. 次のように入れる。
   - 説明：`v6`
   - 次のユーザーとして実行：**「自分」**
   - アクセスできるユーザー：**「全員」**
     - 「全員」にしても、教室コードを知らない人は何も見られません。
5. **「デプロイ」** を押す。（もう一度「承認」の画面が出たら、手順4の4と同じように進める）
6. **「ウェブアプリ」の下にある URL**（`https://script.google.com/macros/s/……/exec`）の右の **「コピー」** を押す。
7. **「完了」** を押す。
8. コピーした URL を、Claude との会話に貼って「API_URL に入れて」と伝える。
   - Claude が `index.html` に入れます。（自分で入れる場合は、`index.html` をメモ帳で開き、`const API_URL='';` の `''` の間に URL を貼って保存）

## 手順8　動くか確かめる

1. `honbun-check` フォルダの **`index.html` をダブルクリック** する（Chrome で開きます）。
2. 教室コードを打って **「次へ」**。
3. **「教室長」** を押す → 管理パスワードを打って **「はじめる」**。
4. **「宿題の配布」** を押す → レッスンで「テスト用　ぼくの犬」を選ぶ → 「中1」の **「全員えらぶ」** → **「えらんだ生徒に配る」**。
5. 右上の **「ログアウト」** → もう一度教室コード → **「生徒」** のまま、生徒番号 `T01`・PIN `1111` で **「はじめる」**。
6. 「テスト用　ぼくの犬」を開いて、少し入力 → ④提出 → **「提出する」**。正答率と ✗ が出れば成功です。
7. 右上の **「ログアウト」** → もう一度教室コード → **「講師」** を押す → 「テスト先生」と講師パスワードで **「はじめる」**。
8. 「テスト 生徒A」の行を押して、下の **「テスト先生としてチェック済みにする」** を押す。日時と名前が出れば成功です。
9. スプレッドシートの **Submissions** シートを見ると、提出が1行ふえ、`checkedBy` と `checkedAt` が入っています。
10. 余裕があれば `tools/console-check.js` の先頭に書いてある使い方で、動作確認スクリプトも実行してください。

## 手順9　本物のレッスンを入れて、配る

レッスン JSON には、必ず `"source"`（出典の文）を入れてください。出典がないレッスンは保存できず、生徒や講師の画面にも出ません。出典は、生徒画面と講師画面のレッスン名のすぐ下に出ます。

### やり方A（おすすめ）：教室長画面に貼る

1. Claude のチャットで、CLAUDE.md の付録のプロンプトを使ってレッスン JSON を作る。
2. JSON をパソコンに保存するときは、`honbun-check` フォルダの中の **`reference` フォルダ** に入れる（このフォルダは GitHub に送られません）。
3. 本文分析ノートを開き、**「教室長」** でログインする。
4. **「レッスン登録」** の大きな白い欄に、JSON を全部貼る（メモ帳で開いて Ctrl + A → Ctrl + C → 欄を押して Ctrl + V）。
   - 1つのレッスン（`{` で始まる）でも、いくつかのレッスンの並び（`[` で始まる）でも貼れます。一度に60レッスンまでです。
5. **「確かめる」** を押す。
   - 赤い字が出たら、そこに書かれたところを直す（わからないときは、赤い字をそのまま Claude に見せる）。並びのときは「3つ目（HWG1-U5-P2）」のように、どのレッスンかが出ます。
   - **1つでもまちがいがあると、どのレッスンも保存できません。** 全部直してから保存します。
   - 「問題なし」と出たら、レッスンごとの「正解を色分けで見る」を押して答えを見直す。
6. レッスンごとの **「生徒の画面で見る」** を押すと、生徒にどう見えるかを試せます（入力しても保存されません）。終わったら **「教室長画面にもどる」**。
7. **「保存する」** を押す。「○レッスンを保存しました」と出たら完了です。
   - 同じ lessonId のレッスンがもう登録されているときは、**上書きします**。「確かめる」を押したときに、そのレッスンの上に「登録ずみのレッスンです。保存すると上書きします」と出るので、まちがっていないか見てから保存してください。
   - 登録ずみのレッスンは、学年 → Unit → Part の順に並びます。
8. **「宿題の配布」** を押す → レッスンを選ぶ → 期限を入れる（なくてもOK）→ 生徒にチェックを入れる（学年ごとの **「全員えらぶ」** も使えます）→ **「えらんだ生徒に配る」**。
   - 配ったレッスンだけが、生徒の一覧と講師の画面に出ます。
   - まちがえて配ったときは、生徒にチェックを入れて **「えらんだ生徒の配布を取り消す」**。下書きと提出は消えません。

### やり方B：スプレッドシートに手で貼る

教室長画面が使えないときの方法です。

1. `reference` フォルダの中にある、**1行にした JSON**（例：`HWG1-U4-P1.oneline.txt`）を **右クリック** →「プログラムから開く」→ **「メモ帳」**。
   - 1行のファイルがないときは、Claude に「○○.json を1行にして」と頼んでください。
2. メモ帳で **Ctrl + A**（全部選ぶ）→ **Ctrl + C**（コピー）。
3. スプレッドシートの **Lessons** シートを開き、一番下の空いている行を使う。
4. 次のように、左のマスから順に入れる。
   - `lessonId`：JSON の中の `lessonId` と同じ（例：`HWG1-U4-P1`）
   - `grade`：例 `中1`（Students の学年と同じ書き方）
   - `textbook`：例 `光村図書 Here We Go! ENGLISH COURSE 1`　`unit`：例 `Unit 4`　`part`：例 `Part 1`
   - `title`：一覧に出る名前（JSON の `title` と同じにする）
   - `json`：このマス（G列）を **1回だけ押す** → 上の **数式バー（fx の右の長い欄）** を押す → **Ctrl + V**（貼りつけ）→ **Enter**。
     - マスを2回押したり、マスに直接貼ったりすると、うまく入らないことがあります。必ず数式バーに貼ってください。
   - `updatedAt`：空のままでOK
5. `json` のマスを押して、数式バーの文字が `{"lessonId"` で始まり、`}` で終わっていることを確かめる。
6. 教室長画面の **「最新にする」** を押す → 「レッスン登録」の下の「登録ずみのレッスン」に出て、**出典の文が見えていれば** 成功です（赤い字で「出典がありません」と出たら、JSON に source が入っていません）。
7. やり方Aの 8 と同じように、**「宿題の配布」** で生徒に配る。

## v5 から v6 に上げる

v6 では、意味調べの採点がやさしくなります。**GAS の再デプロイが必要です。** setup の実行と、承認のやり直しはいりません。

- カタカナとひらがな、全角と半角、空白や「。」「？」のちがいは、同じ答えとみなします（例：「ダレ」「誰？」「だれ」はどれも同じ）。
- 講師画面の、意味調べの ✕ に **「◯にする」** ボタンが付きます。押すと、その生徒の正答率が直り、その答えがレッスンの正解の言葉に足されます（次からはほかの生徒も ◯）。
- 中1の25レッスンの正解の言葉を見直しました（`reference\HWG1-all.json`）。レッスンの登録し直しが必要です。

手順：

1. Apps Script の「コード.gs」の中身を `gas\Code.gs` に入れかえて保存する（まだデプロイしない）。
2. 生徒が使っていない時間に、Claude に「GitHub に上げて」と伝える。
3. 「送りました」と返事が来たら、すぐに再デプロイの 2〜5 を行う（説明は `v6`）。
4. 公開ページの左上が **「v6」** になっているか見る（「v5」のときは **Ctrl + Shift + R**）。
5. 教室長でログイン →「レッスン登録」に `reference\HWG1-all.json` を全部貼る →「確かめる」→「保存する」。25レッスンが上書きされます。
   - 上書きしても、生徒の提出と ◯✕ の記録は消えません。
   - これまでに「◯にする」で足した言葉があれば、上書きで消えます。v6 にしてから「◯にする」を使ってください。

## v4 から v5 に上げる

v5 では、生徒が1問ずつ「確かめる」を押して、すぐに ◯ か ✕ がわかるようになります。**GAS の再デプロイが必要です。** setup の実行と、承認のやり直しはいりません。

- 意味調べは1語ずつ、かたまり・品詞は1文ずつ確かめます。✕ のときは正解とわけが出て、生徒が正しく直してから次の文へ進みます。
- ✕ のあとに「知らなかった・うっかり・考え方がちがった」から選べます（選ばなくても進めます）。
- 提出は1回だけになります（「直して再提出する」はなくなります）。正答率は ◯ の割合です。
- 提出したあと、✕ の問題だけをもう一度解く「解き直し」ができます。宿題の ◯✕ と正答率は変わりません。
- 講師画面に、◯✕ の数・解き直しの結果・ふり返り・「みんながつまずいた問題」が出ます。
- v4 までに提出した宿題は、前の形のまま見えます。v4 で「とちゅう」だった宿題は、答えは残りますが、全部の問題を「確かめる」し直してから提出します。

手順：

1. 下の「GAS のプログラム（Code.gs）を新しくしたとき（再デプロイ）」の 1 を行い、保存だけしておく（まだデプロイしない）。
2. 生徒が使っていない時間に、Claude に「GitHub に上げて」と伝える。
3. 「送りました」と返事が来たら、すぐに再デプロイの 2〜5 を行う（説明は `v5`）。
4. 公開ページの左上が **「v5」** になっているか見る（「v4」のときは **Ctrl + Shift + R**）。
5. テスト用の生徒で、レッスンを1つ最後まで（確かめる → 提出 → 解き直し）やってみる。

## v3 から v4 に上げる

v4 では、①意味調べの画面が新しくなります（挿絵・せりふ全部・日本語訳・単語をタップして意味を見る）。**GAS の再デプロイが必要です。** GAS が Google ドライブを使うようになるので、**もう一度「承認」の画面が出ます。**

1. Apps Script の「コード.gs」の中身を新しいものに入れかえて保存する（下の「再デプロイ」の 1）。まだデプロイはしない。
2. Apps Script の画面で **`setup` を選んで「▷ 実行」** を押す。
   - 「承認が必要です」と出たら、手順4の4と同じように進める（Google ドライブを使う許可が増えています）。
   - ドライブに「本文分析ノート 挿絵」というフォルダができ、Settings シートに `illustrationFolderId` の行が足されます。このフォルダは共有しないでください。
3. 生徒が使っていない時間に、Claude に「GitHub に上げて」と伝える。
4. 「送りました」と返事が来たら、すぐに再デプロイの 2〜5 を行う（説明は `v4`）。
5. 教室長でログインして、「レッスン登録」の **「挿絵の登録」** で、`reference\illustrations` の画像をまとめて選ぶ。
6. 「レッスン登録」に、新しい形のレッスン（lines が入ったもの）を貼って保存する。

lines が入っていない前のレッスンは、今までどおりの意味調べの画面で動きます。

## v2 から v3 に上げる

v3 では、中1の全ユニットを入れられるように、次のことができるようになります。**GAS の再デプロイが必要です。**

- 品詞が14個（名・代・動・助・冠・疑・動名・不・形・副・前・接・間・その他）、かたまりの役割が S・V・O・C・修飾・その他 になります。
- レッスンごとに、生徒に出す品詞と役割のボタンを決められます（JSON の `posSet` と `roleSet`）。
- 「to know」のようにスペースが入った単語も、1つのボタンになります。
- 単語のすぐ後ろのカンマ（`punct`）と、文の話し手（`speaker`）が表示されます。
- 文の最後の記号に `.` `!` `?` が使えます。
- レッスン JSON の並び（`[ … ]`）を貼って、まとめて登録できます。
- レッスンの一覧が Unit・Part の順に並びます。

手順：

1. 下の「GAS のプログラム（Code.gs）を新しくしたとき（再デプロイ）」の 1 を行い、保存だけしておく（まだデプロイしない）。setup の実行はいりません。
2. 生徒が使っていない時間に、Claude に「GitHub に上げて」と伝える。
3. 「送りました」と返事が来たら、すぐに再デプロイの 2〜5 を行う（説明は `v3`）。
4. 公開ページの左上が **「v3」** になっているか見る（「v2」のときは **Ctrl + Shift + R**）。
5. 教室長でログインして、新しい形のレッスン（例：HWG1-U5-P1）を「レッスン登録」に貼り、「確かめる」→「生徒の画面で見る」で、カンマと話し手が出ているかを見る。

v2 に戻すときは、「v1 に戻す」と同じやり方で、GAS は `v2` の版を選び、GitHub は Claude に「v2 に戻して」と伝えます。ただし、v3 の形で登録したレッスン（posSet・roleSet があるもの）は、v2 では正しく表示・採点されません。戻したあとは、そのレッスンを配らないでください。

## v1 から v2 に上げる

v2 では、ログインが「教室コード＋生徒番号＋PIN」に変わり、教室長画面ができます。**GAS の再デプロイが必要です。**

1. 下の「GAS のプログラム（Code.gs）を新しくしたとき（再デプロイ）」の 1〜5 を行う（説明は `v2`）。
2. Apps Script の画面で、手順4と同じように **`setup` を選んで「▷ 実行」** を押す。
   - 足りない行（`adminPass` など）だけが足されます。入っている生徒・講師・提出は消えません。
   - テスト用レッスン（TEST-1）は、出典つきの新しい形に入れかわります。
3. **Settings** シートの `adminPass` の右のマスに、**管理パスワード** を打つ（手順5の4〜6も読んでください）。
   - `teacherPass` は、v1 で打った合言葉がそのまま講師パスワードになります。次に講師がログインしたとき、暗号の形に変わります。
4. **Students** シートの `pin` の列に、生徒ごとに **4けたの数字** を入れる（手順6）。
5. GitHub に新しい `index.html` が上がるのを待つ（Claude が上げます）。そのあと、生徒・講師はみんな一度ログインし直しになります。
6. **大事：** v2 からは、**配ったレッスンだけ** が生徒に出ます（v1 は、配っていない生徒には同じ学年のレッスンが全部出ていました）。教室長画面の **「宿題の配布」** で、使っているレッスンを生徒に配ってください。
7. 手順8のように、動くか確かめる。

## GAS のプログラム（Code.gs）を新しくしたとき（再デプロイ）

Claude が「再デプロイが必要です」と言ったときだけ行います。URL は変わりません。

1. 手順3と同じように、Apps Script の「コード.gs」の中身を新しいものに入れかえて保存する。
2. 右上の **「デプロイ」** → **「デプロイを管理」** を押す。
3. 右上の **✏（えんぴつ）「編集」** を押す。
4. 「バージョン」を **「新バージョン」** にする。説明に `v6` などと入れる。
5. **「デプロイ」** を押す → **「完了」**。

> 「新しいデプロイ」を選ぶと URL が変わってしまうので、必ず「デプロイを管理」から行ってください。
